# TrashGO 🗑️

Proyecto del ramo Taller de Técnicas de Programación - Universidad de Tarapacá.

App móvil para Arica que muestra en un mapa los recorridos de los camiones de basura y los puntos de acopio de la ciudad, además de un foro para que los vecinos puedan comentar sobre temas relacionados a la recolección.

## Sprint 1 (actual)

En este sprint implementamos:

- 🗺️ Mapa interactivo de Arica
- 🚛 Recorridos de los camiones de basura (cuadrantes)
- 📍 Puntos de acopio en el mapa
- 💬 Foro ciudadano (lista de foros + chat)

Por ahora todo funciona con datos de prueba (mock data), todavía no está conectado a un backend.

## Tecnologías

- Flutter + Dart
- flutter_map (OpenStreetMap)
